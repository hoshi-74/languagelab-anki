# 雅思与 N2 轻量听力制卡

听力卡用于保留听不出来但已经理解的表达，不代替完整听力训练。

1. 英语使用 `english_listening` 与 `en_US`；日语使用 `japanese_listening` 与 `ja_JP`。
2. 正面首先自动播放 Anki 原生 TTS。普通卡的任务是听懂并口头复述大意；听写卡的任务是先完整听一遍，再输入原句。
3. 背面依次显示重播按钮、原文、中文含义、必要语境和“辨听复盘”，不要在正面泄露文字答案。
4. 每张卡必须记录 `listening_focus`、`miss_reason` 和数组 `sound_features`：分别说明要听出的意群、此前没听出的主要原因，以及确实存在的连读、弱读、音变、重音或切分线索。
5. 默认 `dictation: false`。只有拼写、连读边界、助词、数字、人名或考试关键词确实需要精确回忆时才设为 true，并填写具体 `dictation_reason`；不能因为“这句很重要”就做听写。
6. 一张卡保持一个短句或短语块。过长句子按完整意义单位拆分，但不要拆坏固定搭配或日语语法结构。
7. 只为“曾经没听出来、但现在已经理解”的内容制卡。尚未理解的材料先讲解，不直接进入听力卡。
8. 如果 TTS 会误读人名、缩写、特殊符号或日语表记，加入人工检查项，不假定所有设备发音一致。

输出必须是 `LanguageLab Card Batch v1` JSON。
