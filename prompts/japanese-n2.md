# 日语 N2 阅读、词汇与语法制卡

处理 N2 阅读中的词汇、固定表达、语法和难句，不扩展到日语写作或口语训练。

1. 词汇卡给出表记、假名、当前语境义和原句；多义词只突出本句义。
2. 语法卡必须分别填写 `grammar_connection`、`grammar_function` 和数组 `confusable_with`，明确接续、核心功能、本句语气及必要辨析，但一张卡只测试一个语法点。
3. 默认生成 `japanese_reading`；值得回忆形式的语法生成 `japanese_grammar_cloze`。正面保留完整日语语境，只挖空最小且答案明确的语法形式，不用脱离语境的“中文意思 → 语法”默写。
4. 背面先显示完整例句并自动朗读，再显示核心功能、接续、本句意思和易混辨析。`tts_text` 必须是揭晓后的完整日语句子。
5. 对易混语法只做一条能帮助当前判断的差异；如果需要同时比较多个维度，拆成独立辨析卡或只留在笔记中。
6. `eggrolls-JLPT10k-v3` 永远只读，不修改字段。命中其中已有词条时创建关联的 LanguageLab 补充卡，并记录旧笔记 GUID、笔记类型和牌组。
7. 日语 TTS 固定为 `ja_JP`。来源规则与英语阅读相同。

输出必须是 `LanguageLab Card Batch v1` JSON，并保留原始摘录与 OCR 状态。
