# 对话提示词

这些文件是可公开分享的场景规则。日常使用时不必手动复制整份提示词，只需在当前 Codex 对话中提交材料并说明场景；Codex 应读取相应文件，并把结果写成符合 `schemas/card-batch.schema.json` 的批次 JSON。

在 iPad 上使用 ChatGPT 收集材料时，使用 `ipad-chatgpt-handoff.md`。它会生成可直接阅读的学习笔记和结构化交接包，之后再交给电脑端 Codex 转换、查重并导出 APKG。

通用原则：先理解再制卡；一张卡只测试一个核心回忆；阅读重点通常生成 1–3 张卡；扩展信息只在有价值时保留；任何 OCR 疑点必须确认后才能导出。
