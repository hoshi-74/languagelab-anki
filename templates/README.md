# Anki 模板

这些模板由生成器读取并写入 APKG。字段名属于 v1 公共接口，导入使用后不要直接改名；结构性变更应建立新的笔记类型版本。

- `basic_*`：英语/日语阅读识别卡。
- `cloze_*`：英语阅读语境填空卡。
- `speaking_*`：雅思口语语境表达卡，背面朗读完整示范句并展示自然替代说法。
- `grammar_*`：日语 N2 语法卡，固定展示接续、功能和必要辨析。
- `writing_*`：雅思写作语境表达卡，正面不输入，背面比较参考句与可接受变体。
- `typing_*`：仅用于答案明确的个人错误纠正卡。
- `listening_*`：Anki 原生 TTS 听辨/听写卡，背面包含未听出原因和声音线索复盘。
- `common.css`：红、蓝、灰、绿、靛蓝五套主题及移动端、深色模式样式。

模板不加载远程脚本、字体或样式表。
